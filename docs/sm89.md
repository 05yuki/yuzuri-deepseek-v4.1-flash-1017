# Ada (SM89) sparse attention

`03-sm89-attention` enables DeepSeek V4 attention on compute capability 8.9.
This repository has not been run on an SM89 GPU.
The patch was validated on one, in a tree with the same SGLang commit; the result is below.

- `serve.sh` accepts Ada.
- The backend selects the fallback by the device's capability.
- SM90, SM100 and SM120 keep their own attention paths.
- It is not a fallback for older GPUs.

On Ada the patch skips FlashMLA's metadata and its SM90+ sparse prefill.
It runs SGLang's dual-scope Triton kernels: the sliding window and the compressed rows in one online softmax, the attention sink included.
The products are BF16 on tensor cores with FP32 accumulation.
Query shapes outside the dual-scope wrapper's contract take SGLang's portable separate-scope Triton path.

Ada keeps the V4 584-byte cache layout (FP8 non-RoPE values, BF16 RoPE, UE8M0 scales).
The V4.1 formats of SM100/SM120 are not enabled on Ada.

## Launch settings

On 8.9 `serve.sh` sets what SGLang itself sets for SM120, each overridable.

- `SGLANG_OPT_USE_TOPK_V2=0`, `SGLANG_OPT_USE_TILELANG_MHC_PRE=0` and `SGLANG_OPT_DEEPGEMM_HC_PRENORM=0` keep the top-k and the mHC pre-step off kernels Ada does not have.
- `SGLANG_FP8_PAGED_MQA_LOGITS_TORCH=1` scores the indexer on its torch path.

The attention's own knobs:

- `SGLANG_SM89_ATTN_SPLITK=auto` (default): eight splits up to four query rows, four up to eight, then the unsplit kernel.
  `0`, `2`, `4`, `8` force one.
  Split 8 on 1,024-row chunks needs about 1 GiB of FP32 partials, so keep `auto`.
- `SGLANG_SM89_ATTN_ROWS=1024`: the prefill query chunk inside attention.
- `SGLANG_SM89_ATTN_DUAL=0`: the portable separate-scope path, for comparisons.

The kernel shape is fixed (`BLOCK_H=16, BLOCK_N=64, num_warps=8`, no autotuning).

## Validation of the patch

On one RTX 4080 SUPER with an experimental 32 GiB memory and two EPYC 7543, in a tree that carried this patch:

- NLL against the checkpoint's reference on that card: 0.7141 reference, 0.7151 served, +0.0010 (SE 0.0041).
- Decode median 31.0 tok/s; 24.7 to 28.1 on the other kinds of text.
- 35K prefill 41.6 s, then 29.7 s.

The 32 GiB card holds the whole 1,048,576-token pool on the GPU.
Retail Ada cards (16 and 24 GB) have not been run.

## Checking an SM89 card

After `setup.sh` has applied the patches:

```sh
python3 tools/test_sm89_dispatch.py third_party/sglang     # CPU only, also in CI
.venv/bin/python tools/sm89-attention-test.py --gpu --no-timing
```

Then run `tools/qualify.sh`.
